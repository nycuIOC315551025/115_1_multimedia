# HW2 影像處理與參數

## 一 實驗材料

我們從 Urban100 選用 013、019、032、087、090 五張照片，每張製作三個版本：

| 圖片版本 | 製作方式 | 資料夾 |
| --- | --- | --- |
| 原圖 | 保留圖片原本的樣子 | `original_image/` |
| 完整處理圖 | 調整整體明暗，再調整局部對比 | `after_image/` |
| 50% 混合圖 | 原圖與完整處理圖的 RGB 像素數值各取一半 | `after_image_hybrid/` |

同一張照片的三個版本保留相同內容與尺寸。「混合一半」是指圖片數值，不代表眼睛看起來的差異也剛好減半。

## 二 處理流程

`main_algorithm.py` 依照以下步驟製作完整處理圖：

1. 把原圖等比縮小至最大 512×512 像素，計算平均亮度。
2. 依平均亮度選擇 Gamma，調整原圖的整體明暗。Gamma 是控制明暗變化的數值，小於 1 會提亮，大於 1 會壓暗。
3. 使用 CLAHE 調整局部對比，也就是各個小區域內的明暗差異。
4. 保留 70% 的 Gamma 校正亮度，加入 30% 的 CLAHE 結果，避免局部調整過強。
5. 轉回 RGB 彩色圖片，存入 `after_image/`。

50% 混合圖在完整處理圖做好後，再由原圖與完整處理圖各取一半，存入 `after_image_hybrid/`。

**兩次混合用途不同：70%／30% 用來製作完整處理圖；50%／50% 用來製作另一種實驗圖片。**

## 三 每張圖片的參數

以下參數使用程式預設的 `--target 0.5`，由五張原圖重新計算。表中保留六位小數，程式實際計算時使用完整精度。

| 圖片編號 | 原圖尺寸（寬×高） | 實際使用的 Gamma | Gamma 步驟的作用 |
| --- | --- | --- | --- |
| 013 | 1024×764 | 0.894669 | 提高亮度 |
| 019 | 1024×680 | 0.833020 | 提高亮度 |
| 032 | 1024×680 | 1.040000 | 降低亮度 |
| 087 | 1024×1024 | 0.912130 | 提高亮度 |
| 090 | 1024×680 | 0.750000 | 提高亮度 |

032 達到 Gamma 上限 1.04，090 達到下限 0.75。這一欄只說明 Gamma 的作用，最後的圖片還會受到 CLAHE 影響。

## 四 五張圖片共用的設定

| 參數 | 設定 | 說明 |
| --- | --- | --- |
| `target` | 0.5 | 估計 Gamma 的參考亮度，不保證輸出平均亮度剛好等於 0.5 |
| Gamma 調整係數 | 0.7 | 減弱自動調整幅度，保留部分原本的明暗感覺 |
| Gamma 範圍 | 0.75–1.04 | 避免調整幅度過大 |
| CLAHE 區塊數 `tiles` | 8 | 把圖片分成 8×8 個區塊，不是每個區塊只有 8×8 像素 |
| CLAHE 對比限制 `clip_limit` | 1.4 | 限制各區塊的直方圖增強幅度 |
| 完整處理圖的亮度混合 | Gamma 70%＋CLAHE 30% | 在亮度通道混合，完成後轉回彩色圖片 |
| 混合圖的像素混合 | 原圖 50%＋完整處理圖 50% | 使用 `Image.blend(original, processed, 0.5)` |

程式在 YCbCr 色彩空間中處理 Y 亮度通道，保留 Cb、Cr 色度通道，最後轉回 RGB。這批圖片使用 Gamma 與局部對比調整，不能直接標成固定的 −0.4 EV 或 −0.6 EV。

<details>
<summary>詳細計算方式</summary>

`μ` 是縮圖的平均灰階值除以 255，範圍為 0–1。預設計算方式如下：

```text
estimated_gamma = log(0.5) / log(μ)
gamma = clip(1 + 0.7 * (estimated_gamma - 1), 0.75, 1.04)
Y_gamma = round(255 * (Y / 255) ** gamma)
Y_output = uint8(clip(0.7 * Y_gamma + 0.3 * CLAHE(Y_gamma), 0, 255))
```

`clip` 表示超過上下限時，取最接近的邊界值。

| 圖片編號 | 縮圖平均亮度 μ | 尚未緩和與限制的估計 Gamma |
| --- | --- | --- |
| 013 | 0.442232 | 0.849528 |
| 019 | 0.402407 | 0.761457 |
| 032 | 0.556815 | 1.183811 |
| 087 | 0.452645 | 0.874472 |
| 090 | 0.264103 | 0.520609 |

CLAHE 使用 256 階直方圖，每區塊的計數上限為 `max(1, int(1.4 * 區塊像素數 / 256))`，相鄰區塊間用雙線性插值銜接。

近乎全黑或全白時（`μ ≤ 0.001` 或 `μ ≥ 0.999`），程式直接回傳原圖和 Gamma 1.0。本次五張照片都沒有進入這個分支。純白區域已經失去的細節，不能靠這個方法還原。

</details>

## 五 執行方式

在 `1_code/HW2` 資料夾開啟 PowerShell，先建立 Python 環境並安裝套件：

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install numpy pillow
```

使用預設參數製作完整處理圖：

```powershell
.\.venv\Scripts\python.exe main_algorithm.py
```

也可以用 `--target 0.6` 改變計算參考值；更改設定後，結果就不再對應上面的預設參數表。程式會寫入 `after_image/`，執行前請先保留要使用的實驗版本。

計算處理前後的亮度指標：

```powershell
.\.venv\Scripts\python.exe exposure_metrics.py
```

這支程式會產生 `exposure_metrics.csv`，並更新本文件最後的亮度指標表。

## 六 結果核對

以預設參數重算五張完整處理圖，得到的 RGB 像素均與 `after_image/` 中的圖片完全一致。再以原圖和完整處理圖各 50% 混合，也均與 `after_image_hybrid/` 一致。

本次核對只比較結果，沒有覆寫圖片。若另行用 EV 或其他方法重製圖片，就應當作另一批刺激，不能直接沿用原圖片的回答。
