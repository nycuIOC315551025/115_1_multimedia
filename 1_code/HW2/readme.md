### 五張圖片共用設定

| 步驟 | 參數 | 設定 |
| --- | --- | --- |
| 平均亮度估計 | 縮圖範圍 | 最大 512×512，等比縮小後轉灰階 |
| Gamma 估計 | `target` | 0.5（計算參考值，不保證輸出平均亮度等於 0.5） |
| Gamma 緩和 | 係數 | 0.7 |
| Gamma 限制 | 下限／上限 | 0.75／1.04 |
| 亮度處理 | 色彩空間 | YCbCr，處理 Y 通道並保留 Cb、Cr，最後轉回 RGB |
| CLAHE | `tiles` | 8，即 8×8 個區塊，不是每區塊 8×8 像素 |
| CLAHE | `clip_limit` | 1.4；每區塊直方圖上限為 `max(1, int(1.4 * 區塊像素數 / 256))` |
| CLAHE | 灰階階數與區塊銜接 | 256 階；相鄰區塊使用雙線性插值 |
| 完整處理圖 | Y 通道混合 | 70% Gamma 校正亮度＋30% CLAHE 結果，裁切至 0–255 並轉為 8 位元 |
| 50% 混合圖 | RGB 像素混合 | 50% 原圖＋50% 完整處理圖，使用 `Image.blend(original, processed, 0.5)` |

注意：70%／30% 是完整處理圖內部的亮度混合；50%／50% 是另外製作第三種刺激條件，兩者是不同步驟。RGB 像素混合也不等於光強度或知覺差異剛好減半。

### Gamma 如何決定

`μ` 是縮圖的平均灰階值除以 255。計算方式為：

```text
estimated_gamma = log(0.5) / log(μ)
gamma = clip(1 + 0.7 * (estimated_gamma - 1), 0.75, 1.04)
Y_gamma = round(255 * (Y / 255) ** gamma)
Y_output = uint8(clip(0.7 * Y_gamma + 0.3 * CLAHE(Y_gamma), 0, 255))
```

近乎全黑或全白（`μ ≤ 0.001` 或 `μ ≥ 0.999`）時，程式直接回傳原圖與 Gamma 1.0，避免無效的對數運算。本次五張圖片均未進入這個分支。

### 與現有圖片的核對

以上設定重算得到的五張完整處理圖，均與 `after_image/` 內對應圖片的 RGB 像素完全一致；以原圖與完整處理圖各 50% 混合後，也均與 `after_image_hybrid/` 一致。此核對未覆寫原圖或處理結果。

`−0.4 EV`、`−0.6 EV` 並非這支程式的設定，也不應用來標示這批圖片。若另行用固定 EV 重製圖片，那是另一批刺激，不能直接套用原圖片的回答結果。

### 建立環境與執行方式

先安裝 Python 3，然後在 `1_code/HW2` 資料夾執行以下指令，建立 `.venv` 並安裝 `requirements.txt` 中的套件：

```powershell
powershell -ExecutionPolicy Bypass -File .\setup_venv.ps1
```

若 `.venv` 已存在，腳本會使用現有環境並安裝所需套件。接著執行：

```powershell
.\.venv\Scripts\python.exe main_algorithm.py
```

程式先根據平均亮度自動選擇 Gamma 值，再對亮度通道套用 CLAHE（限制對比度自適應直方圖均衡化），改善局部對比。CLAHE 結果與 Gamma 校正亮度以 30%／70% 混合，減少過度處理；輸出存入 `after_image`。可用 `--target 0.6` 改變目標亮度（預設為 0.5）。完全過曝成純白的細節無法還原。

安裝套件需要網路連線。若要產生左右對照圖，執行 `.\.venv\Scripts\python.exe compare.py`。
